05 — ЗАПУСК

Що потрібно для підключення

П'ять кроків від чистого середовища до робочого консьєржа. Достатньо, щоб оцінити обсяг — не обов'язково вміти зробити це самому.

Підняти базу даних

Виконати міграції Supabase та засіяти каталог і базу знань, щоб AI мав реальні резиденції й реальні політики для роботи.

Налаштувати AI-процеси

Імпортувати автоматизації n8n і підключити облікові дані — OpenAI для мозку, Telegram для повідомлень, ElevenLabs для голосу.

Розгорнути сайт

Зібрати застосунок Next.js за доменом. Кожен секрет лишається на сервері; браузер ніколи не бачить ключа.

Підключити канали

Спрямувати вебвіджет, Telegram-бота й голосового агента на оркестратор, щоб усі троє мали спільний мозок.

Увімкнути сповіщення й догрівання

Підтвердити домен для надсилання пошти й запланувати завдання сповіщень про об'єкти та догрівання, щоб система працювала й між візитами.
